---
title: Dispatcher
description: decorator-based event dispatcher with automatic webhook setup and token verification
---

## Constructor

```python
from pytonapi.webhook import TonapiWebhookClient, TonapiWebhookDispatcher
from pytonapi.types import Network

client = TonapiWebhookClient("YOUR_API_KEY", Network.MAINNET)
dispatcher = TonapiWebhookDispatcher(
    url="https://example.com",
    client=client,
    accounts=["EQ..."],
    opcodes=["0x7362d09c"],
)
```

| Parameter  | Default  | Description                                            |
| ---------- | -------- | ------------------------------------------------------ |
| `url`      | Optional | Public webhook URL prefix.                             |
| `client`   | Optional | `TonapiWebhookClient` (required for setup/teardown).   |
| `accounts` | Optional | Account IDs to subscribe.                              |
| `opcodes`  | Optional | Opcodes for opcode_msg subscriptions.                  |
| `**kwargs` | —        | Default dependencies injected into handler calls.      |

## Decorators

### @dispatcher.account_tx()

```python
@dispatcher.account_tx()
async def handler(event: AccountTxEvent) -> None: ...

@dispatcher.account_tx("EQ...", "EQ...", path="/custom")
async def handler(event: AccountTxEvent) -> None: ...
```

| Parameter    | Description                              |
| ------------ | ---------------------------------------- |
| `*accounts`  | Account IDs to filter (empty = all).     |
| `path`       | Custom URL path (default: `/account-tx`).|

## Programmatic Registration

Use the `register()` method instead of decorators:

```python
from pytonapi.webhook import WebhookEventType

dispatcher.register(WebhookEventType.ACCOUNT_TX, handler, "EQ...")
```

| Parameter    | Description                              |
| ------------ | ---------------------------------------- |
| `event_type` | `WebhookEventType` enum value.          |
| `handler`    | Callable to invoke on matching events.   |
| `*accounts`  | Account IDs to filter by.                |
| `path`       | Custom URL path for this event type.     |

## Dependency Injection

Pass default dependencies via `**kwargs` in the constructor. Handlers receive only parameters they declare in their signature:

```python
dispatcher = TonapiWebhookDispatcher(url="...", client=client, db=database)


@dispatcher.account_tx()
async def handler(event: AccountTxEvent, db: Database) -> None:
    await db.save(event)
```

Per-request dependencies passed to `process()` take priority over constructor defaults.

<Note>
  Handlers can be async or sync — the dispatcher detects and awaits async results automatically.
</Note>

## setup() / teardown()

`setup()` opens a session, creates webhooks per event type, subscribes, and stores tokens.

`teardown(cleanup)` closes the session. When `cleanup=True`, unsubscribes from all events first.

```python
await dispatcher.setup()

await dispatcher.teardown(cleanup=True)
```

<Note>
  The `client` parameter is required for `setup()` and `teardown()`. Raises `TONAPIError` if `client` is `None`.
</Note>

Subscriptions persist across restarts. On next `setup()`, existing webhooks are reused
via `ensure()` — no duplicate subscriptions are created.

## process()

Parse an incoming event and dispatch to matching handlers:

```python
await dispatcher.process(
    path="/account-tx",
    data=payload,
    authorization=headers.get("Authorization"),
)
```

| Parameter       | Description                              |
| --------------- | ---------------------------------------- |
| `path`          | URL path of the incoming request.        |
| `data`          | Raw webhook payload dictionary.          |
| `authorization` | Value of the `Authorization` header.     |
| `**kwargs`      | Per-request dependencies.                |

The method:
1. Validates the token against stored secrets.
2. Parses the event with Pydantic.
3. Filters by account if the handler specifies accounts.
4. Injects dependencies from constructor defaults + per-request `**kwargs`.

<Note>
  Raises `TONAPIError` if the path is not registered or the authorization token does not match.
</Note>

## paths Property

Mapping of event types to their resolved paths (only includes types with registered handlers):

```python
dispatcher.paths  # {WebhookEventType.ACCOUNT_TX: "/account-tx", ...}
```
