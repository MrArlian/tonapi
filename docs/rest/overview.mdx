<Note>
  TON API returns Pydantic-validated models for every endpoint. If the response shape changes unexpectedly, the SDK raises `TONAPIValidationError` with field-level details.
</Note>

## Errors

TON API may return status codes 400, 401, 403, 404, 405, 409, 422, 429, 500, 501, and 504. See [Guide](/guide#errors) for the full exception hierarchy, descriptions, and handling examples.
