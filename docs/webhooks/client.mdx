## TonapiWebhookClient

HTTP client for creating, listing, deleting, and managing webhook subscriptions.

### Constructor

```python
from pytonapi.webhook import TonapiWebhookClient
from pytonapi.types import Network

client = TonapiWebhookClient("YOUR_API_KEY", Network.MAINNET)
```

| Parameter      | Default  | Description                                    |
| -------------- | -------- | ---------------------------------------------- |
| `api_key`      | Required | API key from tonconsole.com.                   |
| `network`      | Required | Mainnet or Testnet.                            |
| `base_url`     | Optional | Override the default URL.                      |
| `timeout`      | 10       | Request timeout in seconds.                    |
| `session`      | Optional | External HTTP session to share across clients. |
| `headers`      | Optional | Extra HTTP headers.                            |
| `cookies`      | Optional | Extra cookies.                                 |
| `retry_policy` | Enabled  | Retry policy, or `None` to disable.            |

### Methods

#### create(endpoint)

Create a new webhook. Returns a bound `TonapiWebhook` object.

| Parameter  | Description                         |
| ---------- | ----------------------------------- |
| `endpoint` | Callback URL for receiving events.  |

```python
webhook = await client.create("https://example.com/account-tx")
print(webhook.id, webhook.token)
```

#### list()

List all configured webhooks. Returns `list[WebhookInfo]`.

```python
webhooks = await client.list()
for w in webhooks:
    print(w.id, w.endpoint, w.status)
```

#### delete(webhook_id)

Delete a webhook and all its subscriptions.

| Parameter    | Description          |
| ------------ | -------------------- |
| `webhook_id` | Webhook identifier. |

```python
await client.delete(webhook_id=42)
```

#### get_info(webhook_id)

Fetch full webhook information by ID. Returns `WebhookInfo`.

| Parameter    | Description          |
| ------------ | -------------------- |
| `webhook_id` | Webhook identifier. |

```python
info = await client.get_info(webhook_id=42)
print(info.status, info.subscribed_accounts)
```

<Note>
  Raises `TONAPINotFoundError` if the webhook does not exist.
</Note>

#### get(webhook_id)

Get a bound `TonapiWebhook` object by ID.

| Parameter    | Description          |
| ------------ | -------------------- |
| `webhook_id` | Webhook identifier. |

```python
webhook = await client.get(webhook_id=42)
await webhook.subscribe(["EQ..."])
```

#### ensure(endpoint)

Find an existing webhook by endpoint or create a new one. Returns a bound `TonapiWebhook` object.

| Parameter  | Description                         |
| ---------- | ----------------------------------- |
| `endpoint` | Callback URL for receiving events.  |

```python
webhook = await client.ensure("https://example.com/account-tx")
```

## TonapiWebhook

Bound webhook object with methods that do not require an explicit webhook ID.

### Properties

| Property   | Type  | Description                                                                                  |
| ---------- | ----- | -------------------------------------------------------------------------------------------- |
| `id`       | `int` | Webhook identifier.                                                                          |
| `endpoint` | `str` | Callback URL.                                                                                |
| `token`    | `str` | Secret token sent as `Authorization: Bearer {token}` — use for verifying incoming requests.  |

### Methods

#### subscribe(accounts) / unsubscribe(accounts)

Subscribe to or unsubscribe from account transactions.

| Parameter  | Description             |
| ---------- | ----------------------- |
| `accounts` | List of account IDs.    |

```python
await webhook.subscribe(["EQDtFpEwcFAEcRe5mLVh2N6C0x-_hJEM7W61_JLnSF74p4q2"])
await webhook.unsubscribe(["EQDtFpEwcFAEcRe5mLVh2N6C0x-_hJEM7W61_JLnSF74p4q2"])
```

#### get_subscriptions(offset, limit)

Get account transaction subscriptions for this webhook. Returns `list[AccountSubscription]`.

| Parameter | Default | Description                 |
| --------- | ------- | --------------------------- |
| `offset`  | 0       | Pagination offset.          |
| `limit`   | 10      | Maximum number of results.  |

```python
subs = await webhook.get_subscriptions(offset=0, limit=50)
for s in subs:
    print(s.account_id, s.last_delivered_lt)
```

#### subscribe_new_contracts() / unsubscribe_new_contracts()

Subscribe to or unsubscribe from new contract deployment events.

```python
await webhook.subscribe_new_contracts()
await webhook.unsubscribe_new_contracts()
```

#### subscribe_mempool_msg() / unsubscribe_mempool_msg()

Subscribe to or unsubscribe from mempool events.

```python
await webhook.subscribe_mempool_msg()
await webhook.unsubscribe_mempool_msg()
```

#### subscribe_opcode_msg(opcode) / unsubscribe_opcode_msg(opcode)

Subscribe to or unsubscribe from messages with a specific opcode.

| Parameter | Description                        |
| --------- | ---------------------------------- |
| `opcode`  | Opcode in hex format (`0x` prefix).|

```python
await webhook.subscribe_opcode_msg("0x7362d09c")
await webhook.unsubscribe_opcode_msg("0x7362d09c")
```

#### sync_accounts(accounts)

Sync account subscriptions — subscribe missing, unsubscribe extra.

| Parameter  | Description                   |
| ---------- | ----------------------------- |
| `accounts` | Desired list of account IDs.  |

```python
await webhook.sync_accounts(["EQ...", "EQ..."])
```

#### delete()

Delete this webhook and all its subscriptions.

```python
await webhook.delete()
```

## Example

Manual webhook management:

```python
from pytonapi.webhook import TonapiWebhookClient
from pytonapi.types import Network

async with TonapiWebhookClient("YOUR_API_KEY", Network.MAINNET) as client:
    webhook = await client.ensure("https://example.com/account-tx")
    await webhook.subscribe(["EQ..."])
    subs = await webhook.get_subscriptions()
    print(f"Subscribed to {len(subs)} accounts")
```

## Response Models

### WebhookInfo

<Accordion title="WebhookInfo">
| Field                        | Type   | Description                              |
| ---------------------------- | ------ | ---------------------------------------- |
| `id`                         | `int`  | Webhook ID.                              |
| `endpoint`                   | `str`  | Callback URL.                            |
| `token`                      | `str`  | Secret token for Authorization header.   |
| `subscribed_accounts`        | `int`  | Number of subscribed accounts.           |
| `subscribed_msg_opcodes`     | `int`  | Number of subscribed opcodes.            |
| `subscribed_to_mempool`      | `bool` | Mempool subscription active.             |
| `subscribed_to_new_contracts`| `bool` | New contracts subscription active.       |
| `status`                     | `str`  | Current webhook status.                  |
| `status_updated_at`          | `str`  | Last status update timestamp.            |
| `last_online_at`             | `str`  | Last online timestamp.                   |
| `status_failed_attempts`     | `int`  | Consecutive failed delivery attempts.    |
</Accordion>

### AccountSubscription

<Accordion title="AccountSubscription">
| Field              | Type           | Description                        |
| ------------------ | -------------- | ---------------------------------- |
| `account_id`      | `str`          | Subscribed account address.        |
| `last_delivered_lt`| `int`          | Last delivered logical time.       |
| `failed_at`       | `str \| None`  | Timestamp of last failure.         |
| `failed_lt`       | `int \| None`  | Logical time of failed delivery.   |
| `failed_attempts` | `int \| None`  | Number of failed delivery attempts.|
</Accordion>
